## Q2 · 🔴 המכריעה — fallback קשיח או ערך אמיתי?

### פסק: **שניהם. ה-fallback הונצח ל-DB.**

`2500` הוא `DEFAULT_CAPITAL` ב-`src/utils.js:6` — קבוע קשיח-בקוד.
והוא **גם** ערך אמיתי בשורת DB. ⛔ **אלה אינן שתי אפשרויות חלופיות** — זהו
מסלול שבו הראשון הופך לשני **בשקט**. מסלול הקריאה מקצה לקצה, ארבעה שלבים:

**1 · `SwingEdge_App.jsx:1305-1307` — מצב התחלתי**
```js
const [capital, setCapital] = useState(() => {
  try { return parseFloat(localStorage.getItem("swingEdgeCapital")) || DEFAULT_CAPITAL; }
  catch { return DEFAULT_CAPITAL; }
});
```
בהקשר דפדפן נקי (Playwright, וכל מכשיר חדש) `localStorage` ריק ⇒ **ההון מתחיל ב-2500.**

**2 · `src/lib/userSettings.js:101-121` — `loadSettings` בולעת את השגיאה**
```js
const { data, error } = await client.from(TABLE).select("settings")...
if (!error && data && data.settings) { ... return data.settings; }
...
const mirror = readMirror();          // ← דחיית RLS / רשת נופלת מגיעה לכאן
return mirror;                         // ← {} — ⛔ בלתי-ניתן להבחנה מ"אין הגדרות"
```
`error` **נבדק ו⛔ לעולם לא נחשף**. ⚠️ זהו בדיוק הליקוי ש-`INCIDENTS#15` תיקן
ב-`upsertBlob` (`:84-95`, שם `error` נכתב ל-`console.error`) — **ו⛔ לא תוקן כאן.**

**3 · `SwingEdge_App.jsx:1726-1735` — הידרציה מסמנת "הסתיימה" גם כשנכשלה**
```js
if (typeof s.capital === "number" && s.capital > 0) { setCapital(s.capital); ... }
...
hydratedRef.current = true;   // ← ללא תנאי
setHydrationDone(true);
```
בלוב ריק ⇒ ההון **נשאר 2500**, וההידרציה מסומנת כמוצלחת.

**4 · `SwingEdge_App.jsx:1791-1815` — אפקט ההתמדה כותב את ברירת המחדל ל-DB**
```js
if (!authUser?.id || !hydratedRef.current) return;
const patch = { capital, riskPct, lang, ... };
saveSettings(authUser.id, patch);      // ← upsert של 2500 מעל הערך האמיתי
```

### ⇒ המנגנון בשלושה שורשים

- **‹R-4›** — השומר מודד **שההידרציה נוסתה**, ⛔ לא **שהצליחה**.
  ההערה ב-`:1213` מצהירה שהשער מונע דריסה; הוא מונע דריסה **לפני** ההידרציה,
  ⛔ ואינו מונע דריסה **אחרי הידרציה שנכשלה בשקט**.
- **‹R-2›** — ברירת המחדל נכתבת כאילו היא מדידה.
- **‹R-1›** — אחרי הכתיבה ⛔ אין בשורה תעודת מקור: `2500` שנבחר ו-`2500` שנדרס
  נראים **זהים** בטבלה.

### ⚠️ השערה שהעליתי ו**הפרכתי במדידה**

שיערתי ש-`capital` אולי נשמר כמחרוזת ב-jsonb ⇒ `typeof s.capital === "number"`
היה נכשל **לכולם**. `jsonb_typeof(settings->'capital')` מחזיר `number`
ב-**39/39 השורות**. ⛔ **ההשערה הופרכה** ואינה חלק מהממצא.

⇒ **זו משפחת `B-185`** (‹R-2›: fallback שמוצג כנתון) — ⚠️ **אך חמורה ממנה בדרגה**:
ב-`B-185` ה-fallback מוצג בלבד; כאן הוא **נכתב לבסיס הנתונים** ומשמיד את המקור.
