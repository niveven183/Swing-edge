**ה-SQL להרצה ידנית (ניב בלבד, SQL Editor) — שלוש שאלות, שלושה מכנים:**

```sql
-- (א) התפלגות capitalCurrency — האוכלוסייה: כל שורות user_settings
SELECT COALESCE(settings->>'capitalCurrency', '(חסר)') AS cap_ccy,
       COUNT(*) AS n,
       COUNT(*) OVER () AS denom_rows
FROM public.user_settings
GROUP BY 1 ORDER BY n DESC;

-- (ב) capitalCurrency שאינו תואם למטבע העסקאות
-- האוכלוסייה: משתמשים עם >=1 עסקה  ⛔ ולא כל השורות
WITH per_user AS (
  SELECT t.user_id,
         COUNT(*) AS n_trades,
         COUNT(*) FILTER (WHERE t.currency = 'ILS') AS n_ils,
         COUNT(*) FILTER (WHERE t.currency = 'USD' OR t.currency IS NULL) AS n_usd
  FROM public.trades t GROUP BY t.user_id
)
SELECT COUNT(*) FILTER (WHERE us.settings->>'capitalCurrency' = 'ILS' AND p.n_usd > 0) AS ils_cap_with_usd_trades,
       COUNT(*) FILTER (WHERE us.settings->>'capitalCurrency' = 'ILS')                 AS ils_cap_any,
       COUNT(*)                                                                        AS denom_users_with_trades
FROM per_user p JOIN public.user_settings us ON us.user_id = p.user_id;

-- (ג) עסקאות שנחתמו currency='ILS'  ⇒  contradicted  ⇒  יוצאות מלוח הסיכונים
-- האוכלוסייה: כל העסקאות הפתוחות
SELECT COUNT(*) FILTER (WHERE currency = 'ILS') AS ils_stamped,
       COUNT(*)                                 AS denom_open_trades
FROM public.trades WHERE status = 'OPEN';
```

⚠️ **תשובת (ג) היא המספר שקובע את היקף מסלול-התיקון**, ⛔ לא (א).
