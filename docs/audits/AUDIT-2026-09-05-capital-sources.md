**ה-SQL להרצה ידנית (ניב בלבד, SQL Editor) — שלוש שאלות, שלושה מכנים:**

```sql
-- (א) התפלגות capitalCurrency — האוכלוסייה: כל שורות user_settings
SELECT COALESCE(settings->>'capitalCurrency', '(חסר)') AS cap_ccy,
       COUNT(*) AS n,
       COUNT(*) OVER () AS denom_rows
FROM public.user_settings
GROUP BY 1 ORDER BY n DESC;

-- (ב) capitalCurrency שאינו תואם למטבע העסקאות
-- האוכלוסייה: משתמשים עם >=1 עסקה  ⛔ ולא כל השורות
WITH per_user AS (
  SELECT t.user_id,
         COUNT(*) AS n_trades,
         COUNT(*) FILTER (WHERE t.currency = 'ILS') AS n_ils,
         COUNT(*) FILTER (WHERE t.currency = 'USD' OR t.currency IS NULL) AS n_usd
  FROM public.trades t GROUP BY t.user_id
)
SELECT COUNT(*) FILTER (WHERE us.settings->>'capitalCurrency' = 'ILS' AND p.n_usd > 0) AS ils_cap_with_usd_trades,
       COUNT(*) FILTER (WHERE us.settings->>'capitalCurrency' = 'ILS')                 AS ils_cap_any,
       COUNT(*)                                                                        AS denom_users_with_trades
FROM per_user p JOIN public.user_settings us ON us.user_id = p.user_id;

-- (ג) עסקאות שנחתמו currency='ILS'  ⇒  contradicted  ⇒  יוצאות מלוח הסיכונים
-- האוכלוסייה: כל העסקאות הפתוחות
SELECT COUNT(*) FILTER (WHERE currency = 'ILS') AS ils_stamped,
       COUNT(*)                                 AS denom_open_trades
FROM public.trades WHERE status = 'OPEN';
```

⚠️ **תשובת (ג) היא המספר שקובע את היקף מסלול-התיקון**, ⛔ לא (א).

## 6. Q6 — `5.20 → +$5.00` · `40.46 → +$40.00`

### 6.1 הנוסחה

`:4573-4585` — `livePnl = (currentPrice − tr.entry) × tr.shares` (LONG).
`:4617` — עמודת `Now` משתמשת ב**אותו** binding `currentPrice`.

🔴 **`:4621` — האתר:**

```jsx
{liveD ? (liveD.ok ? fmt$(Math.round(liveD.value), liveD.currency) : "—") : "..."}
```

`:5269` — אתר שני זהה (טבלת הג'ורנל).

### 6.2 המדידה — שלוש ההשערות

```
(230.36 − 225.16) × 1 = 5.2000  | Math.round → 5  | fmt$(5)  = +$5.00   | fmt$(5.2)   = +$5.20
(252.87 − 212.41) × 1 = 40.4600 | Math.round → 40 | fmt$(40) = +$40.00  | fmt$(40.46) = +$40.46
shares=2 → 10.40  ⇒ +$10.00 ;  80.92 ⇒ +$81.00
```

| השערה | פסיקה | ההוכחה |
|--------|--------|---------|
| `Math.round` / עיגול | ✅ **אוששה — הסיבה היחידה** | `fmt$(Math.round(5.2))` מחזיר בדיוק `+$5.00` |
| `shares ≠ 1` | ⛔ **הופרכה** | `shares=2` היה מדפיס `+$10.00` / `+$81.00`. ⇒ `shares === 1` בדיוק |
| מחיר שונה מזה שתחת `Now` | ⛔ **הופרכה מבנית** | `:4617` ו-`:4576` קוראים את **אותו** `currentPrice` |

⚠️ **הכשל שקט בדיוק כי `fmt$` מוסיף `.00`** — `+$5.00` נראה כמו סכום מדויק
לסנט, בעוד הסנטים כבר נמחקו. זהו כשל שקט לפי §2. ⚠️ ו-`title=` על אותו
`<span>` (`spotRefusalText(tr, livePnl)`) מקבל את הערך ה**לא** מעוגל ⇒ המסך
והטולטיפ חלוקים.

⛔ **`src/components/MobileTradeCard.jsx` ⛔ אינו מכיל את התבנית** — ⛔ אין בו
`Math.round` ו⛔ אין `livePnl`. שני האתרים חיים ב-`SwingEdge_App.jsx` בלבד.
