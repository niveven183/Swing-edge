## 1. השאילתה המצטברת — הפילוח המלא

הורצה כלשונה, כפי שאושרה:

```sql
select
  case
    when u.email_confirmed_at is null then '1 · נרשם · ⛔ אישר מייל'
    when u.last_sign_in_at    is null then '2 · אישר · ⛔ התחבר'
    when s.user_id            is null then '3 · התחבר · ⛔ סיים אונבורדינג'
    when coalesce(s.settings->'onboarding'->>'completed','') <> 'true'
                                      then '4 · שורת הגדרות · אונבורדינג ⛔ הושלם'
    when coalesce(t.n,0) = 0          then '5 · סיים אונבורדינג · ⛔ שמר עסקה'
    when t.n <= 2                     then '6 · 1-2 עסקאות'
    when t.n <= 4                     then '7 · 3-4 עסקאות'
    else                                   '8 · 5+ עסקאות'
  end as stage,
  count(*) as users
from auth.users u
left join public.user_settings s on s.user_id = u.id
left join (select user_id, count(*) n from public.trades
           where coalesce(is_demo,false) = false group by user_id) t on t.user_id = u.id
group by 1 order by 1;
```

```sql
select
  count(*)                                                          as trades_total,
  count(*) filter (where entry is null or stop is null)             as missing_geometry,
  count(*) filter (where entry is not null and stop is not null
                     and abs(entry-stop) > 25)                      as would_block_at_2874,

                     and abs(entry-stop) > 25)                      as users_affected,

  round(max(abs(entry-stop))::numeric,2)                            as max_risk_per_share,
  round((percentile_cont(0.5) within group (order by abs(entry-stop)))::numeric,2)
```
