## 4 · ארבעה ממצאים ש**אריתמטיקה ⛔ אינה יכולה** להפיק

### 4.1 🔴 גוון ה-accent של הכרטיס **מת** — שתי הצהרות רקע על אותו אלמנט

`StatCard` נושא `${bg}` (למשל `bg-cyan-500/8`) **וגם** `bg-[var(--bg-elevated)]
dark:bg-[#0d1424]` על **אותו `<div>`**. ⛔ סדר ה-class ⛔ אינו קובע — סדר המקור
ב-CSS קובע.

**נמדד:** הרקע האפקטיבי של **חמשת** הכרטיסים הוא `#FFFFFF` (בהיר) / `#0D1424`
(כהה). ⇒ **הגוון ⛔ אינו מרונדר כלל.** אין חמישה כרטיסים מגוונים — יש **חמישה
כרטיסים לבנים זהים**. ⇒ `B-251`. ⚠️ **מחזק את `B-246`:** גם ערוץ ההבחנה השני
(רקע) מת, ⛔ לא רק הגודל.

### 4.2 🔴 שניים מחמשת ה-accents מרונדרים **באותו צבע**

`src/index.css:127-128`:
```css
.text-cyan-400, .text-cyan-500   { color: var(--accent-indigo); }
.text-violet-400, .text-violet-500 { color: var(--accent-indigo); }
```
⇒ `cyan` ו-`purple` שניהם `#0284C7` (בהיר) / `#818CF8` (כהה). **נמדד ישירות.**
⇒ מערכת ה-accent בעלת 5 שמות מרנדרת **3 צבעים נבדלים**. ⇒ `B-252`.
⚠️ זה מאשש עצמאית את «3 צבעים נבדלים» שנמדד ב-`AUDIT-design-system` — אבל מסביר
**למה**, וההסבר ⛔ לא היה בדוח.

### 4.3 🔴 מחלקת **גבול** צובעת מחדש **טקסט** עם `!important`

`src/index.css:424-427`:
```css
[class*="border-cyan-"] { border-color: …; color: var(--accent-emerald) !important; }
```
⇒ כרטיס ה-`cyan` יורש `#00C805` לכל תת-העץ שלו (**נמדד:** `rgb(0, 200, 5)` על
הכרטיס, מול `#4A5848` בארבעת האחרים). ⛔ סלקטור `[class*=]` על מחלקת **גבול**
שמשנה **צבע טקסט** ב-`!important` הוא בדיוק סוג הכשל שאריתמטיקה על הקס בקובץ ⛔
לעולם לא תראה. ⇒ `B-253`.

### 4.4 🔴 הגופן — ⚠️ **מפריך מסקנה שלי מ-26.08 שכבר אושרה**

`SwingEdge_App.jsx:3946` — מעטפת האפליקציה נושאת **`style` inline**:
```jsx
style={{ fontFamily: "'Inter', 'Segoe UI', sans-serif" }}
```
⛔ **inline גובר על `[dir="rtl"] body { font-family: var(--font-hebrew) }`**
(`src/index.css:67`) עבור **כל תת-העץ**.

**נמדד:**

| צומת | `getComputedStyle().fontFamily` |
|---|---|
| `body` | `Heebo, system-ui, sans-serif` |
| המעטפת ו**כל צאצא** | `Inter, "Segoe UI", sans-serif` |

**ו-CDP `CSS.getPlatformFontsForNode` — מה ש**רוסטר** בפועל:**
```
FONT light [data-c1$="-label"] → Lucida Grande×9 , Inter×1
FONT light [data-c1="iui1"]    → Lucida Grande×21 , Inter×7
```

🔴 **שתי מסקנות, שתיהן מפריכות את `M8`/`T8`:**
1. **Inter ⛔ אינו "לא מרונדר" — הוא כן מרונדר**, על התווים הלטיניים.
2. ⚠️ **וגרוע יותר: `Heebo` ⛔ אינו מרונדר כלל בתוך האפליקציה.** התווים העבריים
   נופלים ל-fallback הגנרי של המערכת (`Lucida Grande` ב-macOS). ⇒ הגופן העברי
   **נטען ברשת ואינו בשימוש** בכל מסך `/app`.

🔴 **הצהרה מפורשת:** ניב אימת מ-origin ואישר את הפרמיסה *«`--font-hebrew=Heebo`
⇒ Inter ⛔ לא מרונדר»*, וציטט אותה כשהוציא גופנים מתחום הגל הבא. **הפרמיסה
שגויה, והמקור לשגיאה הוא שלי:** קראתי את שכבת ה-CSS ו⛔ **לא בדקתי `style`
inline**. ⇒ `B-254`. ⛔ **הוצאת הגופנים מהגל הבא ⛔ אינה מבוטלת** — היא הכרעת
ניב, וההנמקה הנוספת (`A-11` · RTL) עומדת בפני עצמה; הפריט נרשם ⛔ ולא מתוקן.
