## Context — למה זה נעשה

הקופי ל-Creative נכתב בריפו נפרד (`swingedge-creatives`) בלי מקור-אמת על מה שהמוצר
באמת עושה. התוצאה הצפויה: קופי שמבטיח יכולת שלא קיימת, או שמפספס יכולת שכן קיימת.
`docs/TRUTH.md` הופך את היכולות הפונות-משתמש למקור-אמת יחיד וניתן לציטוט, וצעד
ב-Fleet Weekly צועק כשהאמת זזה אחרי שהקופי כבר נכתב.

**הסטטוס עודכן לאחר סשן זה:** עץ העבודה היה מלוכלך בתחילת הסשן (עבודת
user-analytics לא מקומטת). במהלך האודיט היא קומטה ונדחפה (`8cc7c80` + `ed6903a`),
העץ נקי ו-`HEAD == origin`. **לא ביצעתי את הקומיט הזה** — הוא נעשה במקביל. שווה
לוודא שלא רצה סשן שני על הריפו (CLAUDE.md §5.3).

## §3 — Fleet Weekly: צעד מוסף בלבד

**שתי מגבלות שנתגלו וקובעות את העיצוב:**
1. `swingedge-creatives` הוא **PRIVATE** — `raw.githubusercontent` מחזיר 404, ו-
   `GH_TOKEN: github.token` מוגבל ל-Swing-edge בלבד. השוואה חוצת-ריפו **דורשת PAT
   חדש** — נפסל (§12 + "אפס תשתית חדשה").
2. ל-fleet-weekly **אין `actions/checkout`** — ולכן `git log` אינו זמין שם.

**העיצוב שנבחר — week-over-week עצמאי:**
- ה-hash דרך ה-API הקיים: `gh api "repos/$GITHUB_REPOSITORY/commits?path=docs/TRUTH.md&per_page=1" --jq '.[0].sha'` — אפס checkout, אפס סוד, `GH_TOKEN` כבר מוגדר בצעד (שורה 54) ו-`gh api` כבר בשימוש (107–109).
- השוואה מול `.fleet-state/truth-hash.txt` — ה-cache **כבר** משוחזר (31–38) ונשמר (188–193). **קובץ נפרד ולא `vitals-prev.json`**, כי האחרון נדרס בסוף הצעד מ-`metrics.tsv` (159–160).
- שונה → שורה `⚠️ TRUTH השתנה מאז הדוח הקודם — בדוק התיישנות קופי` + `color=$AMBER`.
- ריצה ראשונה (אין קובץ) → שורת בסיס, **בלי** אזעקה.
- קריאת API נכשלה → שורת `TRUTH: לא ניתן לקרוא את ה-hash` (§2 אפס כשל שקט) — **לא** שתיקה.
- הדוח **תמיד** מדפיס את ה-hash המקוצר, כדי שיהיה ניתן להעתקה ל-`TRUTH_HASH` בצד ה-Creative.
- **לא** נרשם ב-`metrics.tsv` (hash אינו מספר ואינו מועמד ל-[8.3]).

**מיקום:** בתוך צעד `Weekly Vitals` הקיים, אחרי בלוק trades/week (133) ולפני בלוק [8.3] (135). **אפס שינוי בצעדים קיימים.**

## §6 — אימות

1. `npm run verify` — פלט מלא בדיווח (`test:coach` → `test:import` → `test:settings` → `test:datachain` → `build`).
2. סימולציה מקומית של לוגיקת ה-hash: הרצת שרשרת ה-`gh api` בפועל + שלושת המסלולים (ללא קובץ · hash זהה · hash שונה) מול קובץ זמני **מחוץ** ל-`.fleet-state`.
3. `git push origin main` ואז `git log --oneline -1` מול `git ls-remote origin -h refs/heads/main` — שני hash זהים.
4. דיווח ה-hash הנוכחי של `docs/TRUTH.md` עבור `TRUTH_HASH` בצד ה-Creative.

**לא מריץ dispatch של Fleet Weekly** — הוא פוסט לדיסקורד. אם תרצה אימות חי, תדחוף אתה.
