## 3. השינוי המוצע

### 3.1 להוציא את המחיר ממילון השפה

המחיר **אינו קופי-שפה** — הוא נתון מסחרי. לכן הוא יוצא מ-`STR.he`/`STR.en`
לטבלה אחת בראש הקובץ, ליד שאר ה-consts:

```js
const PRICES = {
  ils: { free: "₪0", pro: "₪25" },
  usd: { free: "$0", pro: "$8"  },
};
```

ארבעת השדות `freePrice`/`proPrice` (:69, :73, :161, :165) **נמחקים** ממילוני
השפה. `freePer`/`proPer` **נשארים** בהם — ראה §7.3.

### 3.2 state מקומי

```js
const [ccy, setCcy] = useState("ils");   // ₪ ברירת מחדל
```

⛔ אפס `localStorage` · אפס query param · אפס ניווט · אפס geo · אפס fetch.
`useState` ותו לא. הרינדור ב-`:1031`/`:1045` הופך ל-`PRICES[ccy].free` /
`PRICES[ccy].pro`. **שני הכרטיסים נקראים מאותו `ccy`** — ולכן ערבוב מטבעות
אינו ניתן לביטוי במבנה, לא רק אסור לפי מוסכמה.

### 3.3 מיקום ה-toggle — מוצע

**בתוך כותרת הסקשן (`:1022–1025`), מתחת ל-`<h2>`, ממורכז,** `marginTop: 18`.
לא בניווט: המטבע נוגע לסקשן אחד, ו-toggle גלובלי היה מרמז שהוא משנה משהו נוסף.

**העיצוב אינו מומצא — הוא מורכב משני דברים שכבר בקובץ:**
גיאומטריית ה-pill והכפתורים מ-toggle השפה (`:699–702` + `activeBtn`/`idleBtn` :642–651),
וצבעי המצע הכהה מהסקשן עצמו (כרטיס Free, `:1028`).

## 8. ⚠️ שלוש הכרעות שאני מבקש לפני ביצוע

1. **`₪25` או `25₪`?** הקוד היום כותב `"0₪"` (סיומת — הנוהג הישראלי הרווח);
   הפרומפט כותב `₪0` / `₪25` (תחילית) פעמיים. **אני הולך לפי הפרומפט (תחילית),
   וזה משנה גם את הצגת ה-Free.** אם העדפתך סיומת — מילה, וזה שני תווים.

2. **מבקר באנגלית — ברירת מחדל ₪ או $?** הקריאה המילולית של "ברירת מחדל:
   תצוגה שקלית" היא `ils` **תמיד**, גם אחרי מעבר ל-EN. זה אומר שדובר אנגלית
   רואה `₪25` עד שילחץ. **החלופה:** ברירת המחדל נגזרת מהשפה (he→₪, en→$)
   ונשארת ידנית אחריה — עדיין אפס geo ואפס fetch, שורה אחת.
   **ברירת המחדל שלי: `ils` תמיד**, כלשון הפרומפט. אשנה אם תאמר.

3. **`package.json` — חריגה מוצהרת מגבול ההיקף.** "אפס נגיעה מחוץ ל-`LandingPage.jsx`
   (מלבד `scripts/`)" אינו מכסה את `package.json`, אבל בלי `test:landing` בשרשרת
   `verify` הבדיקה לא תרוץ לעולם — בדיוק "תלות בזיכרון אנושי" ש-§2 אוסר.
   **מבקש רשות לשתי שורות:** `"test:landing"` + חוליה ב-`verify`.
   אם לא — הבדיקה תיכתב ותורץ ידנית, ואציין שהיא מחוץ לשרשרת.
