### 1.2 🔴 למה תוספת 1 נדחית

## §2 — 🔴 טבלת השער הדרושה אינה קיימת (⛔ אינו באבחון)

**המדידה.** `SwingEdge_App.jsx:1975` בונה את הטבלה **היחידה** באפליקציה:

```js
const { table: fxTable, status: fxStatus } = useFxRates(capitalCurrency, accountCurrency, fxDayKeys);
```

`fx.js:69` דורש התאמת זוג מדויקת:
```js
if (!rateTable || rateTable.quote !== to || rateTable.base !== from) return { value: null, … reason: "no_rate_table" };
```

**פלט מורץ:**
```
convert(54.51,"USD","ILS",<table base=ILS quote=ILS>) = {"value":null,"reason":"no_rate_table"}
convert(54.51,"USD","ILS",null)                       = {"value":null,"reason":"no_rate_table"}
useFxRates(base=ILS, quote=ILS) -> status="identity", table=null, ⛔ אפס קריאות רשת
```

🔴 **בחשבון הצילום (הון ₪ · חשבון ₪) האפליקציה אינה מושכת שער USD→ILS כלל.**
מסלול א' מחייב ⇒ **טבלה שנייה**, `paperCurrency → capitalCurrency`.
זהו פריט העלות הגדול בגל, והאבחון פספס אותו.

### 2.1 ⚠️ תיקון לאבחון — `useFxRates:113`

האבחון קבע: "קיים ותקין — חסר רק `from` נכון". **הופרך חלקית.**
עם `from` נכון (`"USD"`) ומול הטבלה הקיימת (base=`ILS`), `convert` מחזיר
`no_rate_table`, ו-`:114` מחזיר `m` **לא מומר**. ⇒ הכשל **בטוח** (הבאנר נדלק דרך
`pnlByCurrency` הממופתח בנגזר), ⛔ **אך אין המרה.** `from` נכון הוא תנאי הכרחי,
⛔ לא מספיק — §2 נדרש גם.

### 2.2 היקף הטבלה החדשה

הקבוצה הנגזרת סגורה: `{USD, ILS, null}`. ⇒ טבלה אחת, `USD → capitalCurrency`,
נדרשת ורק כאשר `capitalCurrency !== "USD"`. אצל 43/46 המשתמשים
`capitalCurrency === "USD"` ⇒ `base === quote` ⇒ `useFxRates` מחזיר `identity`,
⛔ **אפס רשת ואפס שינוי התנהגות** (`useFxRates:22`).

### 3.2 הכרעת הטהרה — `DecisionCoach` · `localAI` ⇒ ⛔ אפס שינוי חתימה

**ההכרעה: ממירים את `entry`/`stop` באתר הקריאה, ⛔ לא מזרימים `fxTable` פנימה.**

**נימוק — למה זה עדיף על פרמטר אופציונלי (תקדים TradeDNA):**

- `rr` ו-`stopPct` הם יחסים בין שני גדלים באותו מטבע ⇒ **שני האגפים מוכפלים
  באותו שער ⇒ byte-identical.** אין להם מסלול רגרסיה כלל.
- פרמטר אופציונלי הוא ענף שני שרץ רק אצל מיעוט המשתמשים — כלומר ענף שכמעט
  לעולם אינו נבדק בשימוש אמיתי. המרה באתר הקריאה מפעילה **מסלול אחד**.

⚠️ **לאימות בביצוע:** `localAI` מחזיר `metrics.riskPerShare` ו-`metrics.dollarRisk`.
המרת הקלט מְשַׁנָּה את הדנומינציה שלהם. `grep` על הריפו לא מצא צרכן חיצוני לשני

## §4 — מה קורה בלי שער, ומה במטבע לא-מאומת

`convert` ⛔ אינו ממציא שער — מחזיר `{ value: null, reason }`. ⛔ אפס `|| 1`.

| מצב | תמחור פוזיציה (טופס · מחשבון) | תצוגה (24 אתרי מחיר) | מצרפים |
|-----|-------------------------------|----------------------|---------|
| `identity` (43/46) | ⛔ ללא שינוי, byte-identical | סמל נגזר (= הקיים) | ללא שינוי |
| `ready` | מספר נכון | סמל נגזר | מומר |
| `unavailable` / `loading` | **`—` + סיבה מוצהרת** | הערך + סמל הנייר | הבאנר נדלק |
| מטבע לא-מאומת (`AMBIGUOUS`/`CONTRADICTED`) | 🔴 **סירוב מוצהר** | מספר **בלי סמל** (תקדים `QuotePrice:788`) | השורה נספרת כערבוב |

**הנימוק לסירוב** (מהאבחון §4.4, מאושש): פלט תמחור הפוזיציה הוא **הוראת פעולה**
("קנה N מניות"), ⛔ לא תצוגה. §6 מוכיח שהטעות רצה בכיוון של **יותר** חשיפה.
תקדים קיים: `AdminPanel.jsx:993` כבר מסרב להציג סקלר חסר-יחידה.
