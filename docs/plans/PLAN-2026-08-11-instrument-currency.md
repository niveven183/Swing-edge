**ארבע מסקנות נמדדות:**

1. 🔴 **ת"א מוחזרת כ-`ILA`, לא `ILS`.** `ILA` הוא קוד האגורה. **עובדת האגורות
   מקודדת במטבע עצמו** — ⛔ אין צורך בשדה `unit`/`divisor` נפרד עבור נייר
   שהגיע מספק. זה מבטל את ההנחה ב-`AUDIT §5ה` ובמסלול ג' של `AUDIT §6ד`.

2. 🔴 **לא כל מכשיר ת"א נקוב באגורות מבחינת הספק.** מניות וקרנות סל → `ILA`.
   **אג"ח ומדדים → `null`, אין מטבע כלל.** זו התשובה הנמדדת לשאלת §2
   בפרומפט ("אג"ח? קרנות?"): קרנות כן, אג"ח **לא** ⇒ אג"ח ת"א חייבת ליפול
   ללא-מאומת.

3. 🔴 **סימבול לבדו אינו קובע מטבע.** `AAPL` הוא USD/ARS/CAD, `BE` הוא
   USD/MXN/CHF, `TEVA` הוא ILA/USD/EUR — הכל תלוי `exchange`. ⇒ כל גזירה
   מהסימבול בלבד היא ניחוש, **גם עבור סימבול אמריקאי מוכר**.

4. **קריפטו** — `USD` בעקביות ב-4/4 הבורסות שנמדדו.

### ב. 🔴 טיקר מספרי — ההנחה שנפלה

הפרומפט §2 מורה: `טיקר מספרי (^\d+$) → ת"א → ILS, נקוב באגורות`.
**המדידה מפריכה את זה ככלל גזירה:**

| שאילתה | מה TradingView החזיר בפועל |
|--------|------------------------------|
| `1081843` | `101843` @ **SSE** — אג"ח להמרה סינית. ⚠️ **סימבול אחר** (התאמה מטושטשת) |
| `587014` | `567014` @ **SZSE** — אג"ח סינית. ⚠️ סימבול אחר |
| `440016` | `F84023` @ **MILSEDEX** — מוצר מובנה איטלקי, `EUR` |
| `691212` | `S50327` @ **MILSEDEX** `EUR` · `SPFKCF` @ CHIXAU `AUD` · `301592` @ SZSE `CNY` |
| כל ארבעתם מול `&exchange=TASE` | **ריק — אפס תוצאות** |

שלוש עובדות שנובעות:

- **טיקר מספרי אינו ייחודי לת"א.** SSE/SZSE (סין), TSE (יפן), KRX, HKEX —
  כולם מספריים. הכלל היה מסמן אג"ח סינית כישראלית באגורות.
- **ת"א דווקא אינה מאונדקסת לפי המספר** ב-TradingView; היא מאונדקסת לפי
  הטיקר האלפביתי (`TEVA`, `HARL`, `BIG`) ואג"ח בסיומת `.Bn`.
- ⚠️ **חיפוש TradingView מטושטש** — הוא מחזיר סימבול **שונה** בביטחון מלא.
  כל התאמה עתידית חייבת להיות **מדויקת**, אחרת נקבל מטבע של נייר אחר.

⇒ **סעיף המילוט שבפרומפט §2 עצמו הוא שחל:** "אם לא ודאי, סווג כלא-מאומת
⛔ ואל תמיר." טיקר מספרי → **לא-מאומת**, ⛔ לא ILS.

⚠️ זה **אינו** סותר את ההוכחה האריתמטית. ההוכחה מראה ש-13 השורות **הללו**
נקובות באגורות; היא ⛔ אינה מכשירה את `^\d+$ → ILS` כחוק גזירה כללי. שתי
טענות שונות. הראשונה תקפה ומשמשת בגל ב'; השנייה נפסלת.

### ד. 🔴 שתי הנחות מבניות שנפלו

**1. §1 בפרומפט אינו ניתן לביצוע כפי שנוסח.**

הפרומפט מורה לחבר `currency_code` דרך `handleSymbolPick` אל העסקה החדשה.
נמדד:

```
TradingViewSearch  →  מופיע פעם אחת בלבד: SwingEdge_App.jsx:6135
                       בתוך בלוק {/* Watchlist */}  ⇒ מזין watchlist בלבד
טופס העסקה         →  :7085  <input id="log-ticker" ... />
                       טקסט חופשי. ⛔ אין בורר. אין onPick. אין currency_code.
```

מגע הספק היחיד של הטופס הוא `fetchFormQuote` (:2349) → `fetchQuote` →
`api/quote.js`, ושם `currency` מופיע **רק** ב-`:125` ו-`:293` — שני מסלולי
CoinGecko. ⛔ אף מסלול מנייתי אינו חושף מטבע.

⇒ חיווט ה-`onPick` **לא יגיע לעסקה ידנית אחת**. הוא ישפר את ה-watchlist בלבד.

**2. 🔴 "לא-מאומת" אינו ניתן לייצוג ב-DB — מסלול הכתיבה חסום.**

```
currency  text  NOT NULL  DEFAULT 'USD'
CHECK (currency = ANY (ARRAY['USD','ILS']))
```

- כתיבת `null` → נדחית (NOT NULL).
- השמטת המפתח → `tradeForSupabase` מוריד אותו → **Postgres מחזיר `'USD'`**.
  כלומר הסרת השורה `currency: capitalCurrency` ⛔ **אינה** מפסיקה את הניחוש —
  היא רק מעבירה אותו מהלקוח לשרת.
- `ILA` נדחה ע"י ה-CHECK ⇒ אגורות אינן ניתנות לאחסון גם כשהן נמדדות.

⇒ **הפסקת ההצהרה בכתיבה דורשת מיגרציה.** מיגרציה אסורה בגל הזה, וממילא §12
קובע שניב מריץ. ⇒ הגל הזה מפסיק את ההצהרה **בקריאה**, וזה בדיוק מה
שהפרומפט §2 ממילא דורש: "נגזר בזמן קריאה, ⛔ לא נשמר".

## 3. הגזירה — `src/lib/instrumentCurrency.js`

מודול טהור. תקדים: `riskProfile.js` · `equityBase.js` · `tradeHorizon.js`.

### א. ארבעה מצבים

| `MEASURED` | קוד מספק, מנורמל | ✅ |

| `CONTRADICTED` | ראיה חיובית שהתווית שגויה | ⛔ |

### ב. ה-API

```js
normalizeProviderCurrency("ILA") // → { code: "ILS", minorUnit: 100 }
normalizeProviderCurrency("USD") // → { code: "USD", minorUnit: 1 }
normalizeProviderCurrency(null)  // → null   ⛔ לא ברירת מחדל

deriveInstrumentCurrency(trade)
// → { code: "USD"|"ILS"|null, minorUnit, state, reason }
// ⚠️ נגזר בזמן קריאה. ⛔ לעולם לא נשמר, אין דגל ב-DB, אין state בין רינדורים.

isAggregatable(derived)  // MEASURED | ASSUMED
```

### ג. סולם הראיות — לפי הסדר, עצירה בהתאמה ראשונה

1. **קוד ספק שנמדד** → `MEASURED`. גובר על הכל, כולל `trade.currency`.
   (בגל הזה: 0/61 שורות. הענף קיים ונבדק, ומופעל כשהמיגרציה תיפתח.)
2. **טיקר מספרי `^\d+$`** → `AMBIGUOUS`. ⛔ **לא ILS.** נימוק: §1ב.
3. **זוג קריפטו ששמו נוקב במטבע** (`BTCUSD`, `BTC-USD`, `…USDT`) → `MEASURED` USD.
4. **`trade.currency === "ILS"` על טיקר אלפביתי** → `CONTRADICTED`.
   נימוק: אין מסלול שבו נמדד ILS אי-פעם (0/61), והתווית ILS יכולה היה להיכתב
   **רק** ע"י `:2457` מהעדפת החשבון. היא עדות על המשתמש, לא על הנייר.
5. **אחרת** (טיקר אלפביתי, תווית USD) → `ASSUMED`.

⚠️ **§2 בפרומפט מבקש `ILS`+אגורות לטיקר מספרי. התוכנית סוטה במכוון** —
המדידה ב-§1ב מראה שזה ניחוש. הסטייה **אינה** מרככת את הטיפול ב-13 השורות:
`AMBIGUOUS` מוציא אותן מהמצרפי בדיוק כמו שההמרה הייתה עושה, ובלי להמציא
מספר. הכימות באגורות נשאר לגל ב', שם הוא נשען על ההוכחה האריתמטית
לשורות **הללו** ולא על חוק כללי.

### ד. קריפטו — ההכרעה והנימוק

**הכרעה: זוג ששמו נוקב במטבע → אותו מטבע, `MEASURED`.**

נימוק: `BTCUSD` אינו סימבול שיש לו מטבע — הוא **יחס**, וה-`USD` בשמו **הוא**
המכנה. זו קריאה של שם המכשיר, לא הסקה עליו. נתמך בשתי מדידות בלתי תלויות:
TradingView מחזיר `USD` ב-4/4, ו-`api/quote.js` מבקש `vs_currency=usd`
מפורשות ⇒ התשובה דולרית בהגדרה.

⚠️ **זה המקום היחיד במודול שבו מחרוזת נחשבת ראיה.** מסומן ככזה בקוד, ומוגבל
לרשימה סגורה של קודי מטבע בסיומת. `BTC` לבדו → ⛔ לא נכנס לענף הזה.

### ה. ת"א ואגורות

- `ILA` מספק → `{ ILS, minorUnit: 100 }`. **עובדת האגורות מגיעה מהספק**, ⛔ לא
  מהנחה שלנו.
- אג"ח/מדד ת"א → הספק מחזיר `null` → `AMBIGUOUS`. ⛔ אין המרה.
- ⛔ **`minorUnit` אינו מיושם על שורות קיימות בגל הזה.** הוא נגזר ומדווח;
  היישום על 13 השורות הוא גל ב'.

## 4. מה רואה משתמש עם "לא-מאומת"

⚠️ ⛔ לא נמחק · ⛔ לא מוסתר · ⛔ לא מוחלף באפס.

**ביומן** — העסקה מוצגת מלאה. `entry`/`stop`/`target`/`shares` **ללא שינוי**
(הם נכונים; רק התווית שקרית). שדות שדורשים חישוב חוצה-יחידות — סיכון בכסף,
סיכון ב-%, R, P&L במטבע החשבון — מציגים `—` עם צ'יפ **"מטבע לא מאומת"**.
Tooltip: המערכת מעולם לא מדדה באיזה מטבע נסחר הנייר; המספר **נמנע** ולא
נוחש. ⛔ אין CTA לתיקון בגל הזה — התיקון הוא גל ב', אחרי הודעה מוקדמת.

**בסטטיסטיקות** — השורות מוחרגות מהמצרפי, **וההחרגה מוצגת עם מכנה**
(CLAUDE.md §2): `13/61 עסקאות הוחרגו — מטבע לא מאומת`. ⛔ לא הערת שוליים,
⛔ לא השמטה שקטה.

**באנר ערבוב** — נדלק (§6ג).

## 5. ⚠️ ההכרעה שנשארת לניב

**המלצה:** השער אינו "האם כל שורה מאומתת" אלא **"האם הקבוצה מוכחת

`mixedCurrency` הקיימת.

**חלופה מחמירה:** גם 47 יוצאות. עקבית יותר לדוקטרינה, מרוקנת את המוצר.

⛔ **החלטת מוצר. אני לא מכריע אותה לבד.** התוכנית נכתבה סביב ההמלצה; מעבר
