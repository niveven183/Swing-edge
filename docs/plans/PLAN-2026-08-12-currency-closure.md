2. **טיקר מספרי מקצר לפני כן.** `:139` — `NUMERIC_TICKER` ⇒ `AMBIGUOUS`,
   **לפני** ש-`stored` נקרא בכלל. 13 שורות ת"א הן מספריות

⇒ **החשיפה 101.5455× נשארת 101.5455×.** ⛔ התיקון אינו נוגע בה, מפני שהתיקון

אומר: **"13 ת"א באגורות מתויגות `USD`"**. ⇒ גם נקודת המוצא בפרומפט שגויה.

### §0.3 §3 — `currency=null` נכנס למצרפים **בשקט**

```
=== §3 premise: currency=null must yield UNVERIFIED, not ASSUMED ===
currency:null,  alpha ticker    {"code":"USD","state":"assumed"}    | aggregatable: true  | unverified: false
currency omitted, alpha ticker  {"code":"USD","state":"assumed"}    | aggregatable: true  | unverified: false
currency:null,  numeric ticker  {"code":null,"state":"ambiguous"}   | aggregatable: false | unverified: true
```

`instrumentCurrency.js:150-151` — "אין ראיה נגד ⇒ נכנס למצרפי".
⇒ **הפסקת החתימה ב-`:2576` היא רגרסיה, ⛔ לא תיקון:**

| | היום (`currency: capitalCurrency`) | אחרי "הפסק לחתום" |
|---|---|---|
| משתמש שקלי רושם AAPL | `'ILS'` ⇒ **`CONTRADICTED`** ⇒ unverified ⇒ **מחוץ למצרפים + שבב** | `null` ⇒ **`ASSUMED USD`** ⇒ **נכנס למצרפים בשקט** |

**היום המערכת מסרבת בקול. אחרי השינוי היא מניחה בשקט.** זה בדיוק מה שהפרומפט
עצמו הגדיר כתנאי עצירה, וזה גם מה ש-`CLAUDE.md` §2 קורא לו "ברירת מחדל שמחליפה
נתון אמיתי".

⚠️ **ולכן הנימוק "השקר הוא הראיה" ⛔ לא פג.** המיגרציה יצרה ייצוג ל-`NULL`
**ב-DB**, אבל **הגזירה ⛔ אינה מבדילה** בין `NULL` לבין "לא צוין" — שניהם נופלים
ל-`ASSUMED`. הייצוג קיים בשכבה אחת ואינו קיים בשכבה שמכריעה.

### §0.4 מה **כן** עובד — שורת BE

```
=== BE row (alpha ticker) — BEFORE vs AFTER ===
BEFORE  currency=ILS (today)   state=contradicted  code=null  aggr=false  symbol=₪  -> +₪3,240.00
AFTER   currency=USD           state=assumed       code=USD   aggr=true   symbol=$  -> +$3,240.00
```

✅ שורה אחת, טיקר אלפביתי, נייר NASDAQ. `'ILS'` → `'USD'` עושה **בדיוק** את מה
שהפרומפט מתאר: השבב נעלם, הסמל חוזר ל-`$`, השורה חוזרת למצרפים.
