## מימוש — קובץ יחיד: `src/lib/instrumentCurrency.js`

⛔ **לא נוגעים:** `PAIR_QUOTE` · בלוק `provider_code` (:181-184) ·
`ils_never_measured` (:203) · הגדרת `isEvidenceBacked` (:112-113) ·
כל שדה/עמודת DB. הענף החדש **קורא** את `isEvidenceBacked` ואת
`normalizeProviderCurrency` הקיימים — ⛔ אינו משכפל את רשימת "אילו ערכים
הם ראיה" (כבר קיימת ב-`EVIDENCE_SOURCES`, :104-107).

```js
export const deriveInstrumentCurrency = (trade, opts = {}) => {
  // 1. קוד ספק שנמדד — גובר על הכל.
  const measured = normalizeProviderCurrency(
    trade?.instrumentCurrency ?? opts.providerCurrency
  );
  if (measured) return { ...measured, state: MEASURED, reason: "provider_code" };

  // 1.5 — B-172: תווית שנקנתה בראיה בזמן ייבוא/הזנה (B-129), ⛔ לא היסק חדש.
  //       currency_source אומר *איך* התווית נקבעה; normalizeProviderCurrency
  //       עדיין הפילטר היחיד על *מה* המטבע (USD/ILS/ILA בלבד).
  if (isEvidenceBacked(trade?.currency_source)) {
    const evidenced = normalizeProviderCurrency(trade?.currency);
    if (evidenced) return { ...evidenced, state: MEASURED, reason: "currency_source_evidence" };
  }

  const ticker = normalizeTicker(trade?.ticker);
  if (!ticker) return unmeasured(AMBIGUOUS, "no_ticker");
  … (שאר הפונקציה ללא שינוי)
```

⚠️ **הערת התיעוד הקיימת בראש הקובץ (:25-43, שמסבירה למה `MEASURED`
בלתי-נגיש) נדרשת עדכון באותו קומיט** — הענף החדש הופך אותה לחלקית שגויה
(היא עדיין נכונה לגבי `provider_code`, אבל לא עוד לגבי "0 מקורות
מחוברים"). מוסיפים פסקה קצרה, ⛔ לא מוחקים את הקיימת — היא עדיין נכונה
לגבי 0/78 השורות **היום**.

   → ⛔ **לא** דרך הענף החדש — זהה להתנהגות טרום-הגל (67 השורות הישנות).

   `currency_source_evidence`).
6. רגרסיה — `pair_quote`/`numeric`/`alpha` בלי `currency_source` נשארים
