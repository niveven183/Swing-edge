## חלק 1 — ארבעת פגמי הסיור

### `B-350` · `tourDone` ⛔ מגיע ל-DB

`completeTour` (`:1309-1315`) כותב ל-localStorage בלבד. אפקט ההתמדה (`:1841-1866`)
קורא `swingEdgeTourDone` מ-localStorage, אבל מערך התלות שלו (`:1866`) ⛔ מכיל אותו
⇒ הכתיבה נוחתת רק כש**הגדרה אחרת** משתנה. בין לבין, מכשיר שני מריץ את הסיור שוב.

**התיקון:** מסלול כתיבה **משלו**, באותה צורה כמו `welcomeSeen` (`:1300`):
`saveSettings(authUser.id, { tourDone: true })` בתוך `completeTour`, ו-`authUser?.id`
נכנס למערך התלות של ה-`useCallback`.
⛔ **לא** נגיעה באפקט ההתמדה — `test:hydration` מחלץ את גופו לפי עוגן, וכל שינוי שם
הוא אדום-קשה (`B-272`). ה-`patch.tourDone` הקיים נשאר כסנכרון אופורטוניסטי; שניהם
נגזרים מאותה כתיבת localStorage ⇒ ⛔ סחיפה.

### `B-351` · `data-tour="add-trade"` על שני אלמנטים

`:5267` (כפתור מצב-ריק, מרונדר רק כש-`trades.length === 0`) ו-`:8398` (ה-FAB, תמיד).
`document.querySelector` לוקח את הראשון ⇒ בעץ ריק הסיור מצביע על כפתור שייעלם
ברגע שתיווצר עסקה.

**התיקון — בשורש:** `:5267` מקבל `data-tour="add-first-trade"`. `add-trade` נשאר
על ה-FAB **בלבד** ⇒ ייחודי **וגם** תמיד נוכח. הסיור (`:1082`, `:1083`) ⛔ משתנה.

**באותו קומיט** — הסנטינל: `.last()` ב-`:783` וב-`:815` יורד, וההערה שמסבירה
אותו (`:810-811`: «`.last()` is the global FAB…») יורדת איתו. עקיפה שנשארת אחרי
שהשורש תוקן היא תיעוד שקרי.

### `B-352` · חיצים מקודדים קשיח

`OnboardingTour.jsx:97-98`: `ArrowRight` → `next`, `ArrowLeft` → `back`, וה-`useEffect`
נושא `[]` ⇒ ⛔ רואה את `isRTL` לעולם. בעברית הניווט הפוך.

**התיקון:** מיפוי נגזר — `const fwd = isRTL ? "ArrowLeft" : "ArrowRight"`, והמאזין
משווה מולו. `isRTL` נכנס למערך התלות.
⛔ **ה-`navRef` נשאר** — הוא מה שמונע re-trap של המאזין בכל צעד; ההחלפה היא
ב**מפתח**, ⛔ בארכיטקטורת ה-ref.

### `B-353` · `onNavigate` בלי ולידציה

`:58`: `if (stepTab) { try { onNavigate?.(stepTab); } catch {} }` — כל מחרוזת עוברת.
צעד שמצביע לטאב מחוק נכשל **בשקט** ב-12 ניסיונות × 100ms = 1.2s תקיעה, ואז בועה

**התיקון — כשל רועש, ⛔ שקט:** הרכיב מקבל `navKeys` (מערך המזהים החוקיים).
`stepTab` שאינו בו ⇒ `console.error` מפורש עם המזהה והצעד, ו-`onNavigate` ⛔ נקרא.
⛔ **אין `|| "dashboard"`** — ניווט מנוחש הוא `R-2`; הודאה רועשת היא התשובה.
⚠️ `navKeys` ריק/חסר ⇒ ולידציה ⛔ מופעלת (תאימות לאחור), וזה **מוצהר** בהערה.
