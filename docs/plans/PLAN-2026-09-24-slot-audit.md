## 3. מה נבנה

### 3.1 `scripts/slot-audit.mjs` (חדש)

```
node scripts/slot-audit.mjs --workflow sentinel.yml [--window-hours 24]
                            [--grace-hours 7] [--fixture <path>] [--out slot-embed.json]
```

1. **מכנה** — קורא `.github/workflows/<wf>` מהדיסק, מפרסר `on.schedule[].cron`,
   מרחיב 5 שדות, סורק דקות בחלון, מחזיר **ספירת סלוטים נומינליים + רשימתם**.
   `window = max(--window-hours, 2 × period)`, מסתיים `now − grace`.
2. **מונה** — `GET /actions/workflows/<wf>/runs?event=schedule` (עמודים), מסנן
   `created_at` בחלון, גורע `created_at != run_started_at` **ומדפיס את הספירה**.
3. **הימנעות רועשת** — `GET /commits?path=.github/workflows/<wf>&since=<window start>`.
   `length > 0` ⇒ יציאה במסלול **`⛔ ניתן למדוד`** עם ה-sha והתאריך, צבע **אמבר**,
   ⛔ ירוק ו⛔ אחוז. ⚠️ **contents API ⛔ `git log`** — כל checkout בריפו הוא
   `fetch-depth: 1` ⇒ ההיסטוריה אינה על הדיסק. נמדד שהקריאה עובדת (`0` בחלון
   הנוכחי; הקומיט האחרון ל-`sentinel.yml` הוא `d0d7940` · `2026-09-11T14:37:02Z`).
4. **מכנה 0** ⇒ `«0 סלוטים חלפו — אין מה למדוד»`, ירוק, **⛔ אחוז**.
5. **פלט** — `slot-embed.json` = `{color, description}` לפי חוזה `post`, ותמיד
   **מונה/מכנה + שם האוכלוסייה** (§2), גם ב-🟢.
6. `--fixture` מזריק מערך ריצות ושעון קפוא ⇒ ⛔ API במבחן.

⛔ **`|| 0` / `?? 0` בכל המסלול** — מכנה שנעדר ונופל ל-0 הוא `R-2`; מונה שנעדר
מדווח כהימנעות. ⛔ **ענף שמחזיר `null`/שותק** — כשל בפרסינג הוא **אדום/אמבר רועש**.
