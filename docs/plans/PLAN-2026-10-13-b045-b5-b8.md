## 3 · התיקון (קובץ קוד אחד: `SwingEdge_App.jsx`)

משנים **רק את שורת ה-calc** בכל בלוק. שורות העוגן של `test:cents` נשארות byte-identical: `.map(m => ({ ...m, pnl: m.pnl }));` ו-`return { hold, pnl: pnl, ticker: t.ticker };`. לכן `test:cents` ו-`probe:cents:mutants` ⛔ לא נערכים (בניגוד ל-B3, שבו התיקון כתב מחדש את שורת ה-payload).

```js
// B5
const { pnl, fxUnconverted } = stableCalcTradeMetrics(t);
if (pnl == null || fxUnconverted) return;
// B8
const { pnl, fxUnconverted } = stableCalcTradeMetrics(t);
const hold = holdDays(t);
if (pnl == null || fxUnconverted || hold == null) return null;
```
