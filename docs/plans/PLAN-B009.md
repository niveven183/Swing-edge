## 1 · הכלל שמכריע כל מפתח — ⛔ לא "נראה לי"

ניב ניסח: *"null אם״ם הערך ⛔ אינו מדיד מאפס עסקאות"*. הניסוח המבצעי:

> **`0` נשאר אם״ם `0` הוא איבר-היחידה של הצבירה **וגם** `0` בתוך הטווח שהמדד
> רשאי לדווח בכלל.**

סכומים ומונים — איבר היחידה שלהם על הקבוצה הריקה הוא `0`, ולכן `0` הוא **מדידה**.
מנות (`avg`, `rate`, `%`) וקיצוניות (`max`, `min`) — ⛔ אין להן איבר יחידה על
הקבוצה הריקה, ולכן `0` שם הוא **המצאה**.

**מבחן ההתנגשות (בדיקה שנייה, מכריעה):** פליטת `V` על ריק אינה לגיטימית אם
המסלול החי מייצר `V` תחת תנאי **אחר ומשמעותי**. אם קיימת התנגשות — הצופה ⛔ אינו
יכול להבדיל בין "לא נמדד" לבין "נמדד ויצא V", וזה בדיוק `R-2`.

## 3 · `isEmpty` מקבל צרכן אמיתי — ⛔ ומפסיק להיות תירוץ לדילוג

**המצב היום (מדוד):** `tradingStats.js:276,301` מייצר · **0 צרכנים ב-`src/`** ·
הצרכן היחיד בכל הריפו הוא `scripts/tradingstats-test.mjs:99`, והוא משתמש בו כדי
**לדלג**:

```js
const ratesSumTo100 = (label, s) => {
  if (s.isEmpty) return;                     // ← R-3
  close(`${label} — winRate + lossRate + beRate === 100`, …);
```

**שני שינויים, שניהם חובה:**

**(א) צרכן ב-`src/` — `B-157`.** `SwingEdge_App.jsx:4816` מגדר על
`closedTrades.length > 0` (**האוכלוסייה הלא-מסוננת**) ומדפיס `journalStats`
(**המסוננת**). ⇒ פילטר שאינו מכיל אף עסקה סגורה מציג **7 תאים מומצאים**. זהו
**המסלול היחיד שבו משתמש פעיל רואה `EMPTY_STATS`**. השער הופך ל:

```jsx
{!journalStats.isEmpty && ( … )}
```

⇒ `isEmpty` הופך ל-load-bearing במסך, ו-`B-154` נסגר בפועל ולא בהצהרה.

**(ב) המבחן מפסיק לדלג.** `ratesSumTo100` ⛔ אינו יוצא מוקדם — הוא **מסתעף**:

```js
const ratesSumTo100 = (label, s) => {

    eq(`${label} — ריק: lossRate === null`, s.lossRate, null);
    eq(`${label} — ריק: beRate === null`,   s.beRate,   null);
    eq(`${label} — ריק: wins+losses+be === 0`, s.wins + s.losses + s.be, 0);

```

⚠️ **זה הופך את `isEmpty` מ"רשות לא לבדוק" ל"חוזה שנבדק".** ⛔ אין מצב שלישי.
