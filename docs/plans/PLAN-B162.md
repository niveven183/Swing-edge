## 2 · השינוי בקוד — `scripts/registry-test.mjs`, בדיוק

### 2.1 · וריאנט D — העברת הווטו

היום (`:483-490`):

```

  const p = strip(cell);
  if (DENIED.test(p)) return { ok: false, why: "..." };        ← :485  הווטו, על כל התא
  for (const m of p.matchAll(EYE)) {                            ← :486

```

אחרי:

```
export function markerVerdict(cell, performed) {
  const p = strip(cell);
  for (const m of p.matchAll(EYE)) {
    if (!denied(p, m.index, m[0].length)) return { ok: true, ... };
  }
  if (DENIED.test(p)) return { ok: false, why: "..." };        ← הווטו, אחרי הסמן ולפני המצביע
  const refs = [...new Set(cell.match(/C-0\d\d/g) ?? [])];
```

**זו כל התזוזה.** מה שהיא משנה, ורק זה:

| מצב | היום | אחרי |
|-----|------|------|
| סמן תקין + הכחשה **רחוקה** ב-`DENIED` | ✘ נופל (`:485` יורה ראשון) | ✔ עובר — **ענף הקרבה נעשה נגיש** |
| הכחשה **צמודה** לסמן + מצביע `C` רחוק שבוצע | ✘ נופל (`:485`) | ✘ נופל — **הווטו עדיין קודם ל-`C-0xx`** |
| הכחשה בלבד, ⛔ בלי סמן | ✘ נופל | ✘ נופל |
| הכחשה רחוקה ב-`DENY_NEAR` בלבד + סמן תקין | ✔ עובר | ✔ עובר |

⚠️ **המשמעות המדויקת:** הווטו ⛔ לא נחלש ו⛔ לא נמחק — הוא ירד מדרגה אחת, מ"קודם
לכל" ל"קודם לראיה **העקיפה**". הודאה מפורשת עדיין גוברת על מצביע `C-0xx`; היא
כבר ⛔ אינה גוברת על סמן חיובי ש**נמדד כלא-מוכחש בקרבתו**.

### 2.2 · הערה שנוספת מעל הווטו במקומו החדש
