# Email Campaign — SwingEdge

**שליחת מייל היא בלתי הפיכה.** אין "בטל שליחה". כל מה שכאן קיים כדי שלא נשלח
דבר שגוי לאדם אמיתי.

## מקורות אמת

| מה | איפה |
|---|---|
| מנוע השליחה | `.github/workflows/email-campaign.yml` |
| תבניות | `emails/*.html` |
| dedup + היסטוריה | `public.email_campaign_log` (`campaign` + `email`) |
| נוהל מלא | `docs/RUNBOOK.md` § "שליחת קמפיין מייל" |
| שליחה בודדת מהפאנל | `api/send-invites.js` — **מסלול אחר, לא נוגעים בו כאן** |

## שלושת הקהלים

| audience | מי | מיון |
|---|---|---|
| `waitlist_approved` | נרשמי רשימת המתנה עם `approved_at IS NOT NULL` | — |
| `registered_users` | כל מי שיש לו חשבון | `created_at ASC` |
| `stuck_users` | חשבון ≥7 ימים · ≤1 עסקה · לא אדמין | `last_sign_in_at DESC` |

⚠️ `registered_users` שולח ל**כל** בעלי החשבון. `LIMIT 5` = 5 הוותיקים ביותר,
לא 5 הרלוונטיים. לבחירת קהל לפי התנהגות — `stuck_users`.

## הזרימה — חמישה שלבים, עצירה קשיחה באמצע

### 1. תבנית
- HTML ממותג בלבד. **לעולם לא טקסט חשוף** (`CLAUDE.md`).
- נגזרת מ-`emails/waitlist_launch.html`: header `#070B0A` + לוגו
  `SWING` + `EDGE` ב-`#00C076`, RTL, גוף לבן, footer `#f9fbf8`.
- CTA ל-`https://swing-edge.com/?utm_source=email&utm_campaign=<שם>`.
- נשמרת כקובץ ב-`emails/` ומקומטת **לפני** כל שליחה.
- Code לא ממציא תבנית ולא "משחזר" אותה. אין קובץ → STOP.

### 2. שם קמפיין
- שם חדש לכל קמפיין. שם חוזר → ה-dedup חוסם את כולם ולא יישלח דבר.
- ביטול רישום שגוי:
  `delete from email_campaign_log where campaign='X';`
  Supabase יזהיר "Potential issue detected" על כל `delete` — לגיטימי, לקרוא לפני אישור.

### 3. הרצה יבשה — חובה
```
gh workflow run email-campaign.yml --ref main \
  -f campaign=<שם> -f audience=<קהל> \
  -f subject="<נושא>" -f template=emails/<קובץ>.html \
  -f dry_run=true -f limit=<מספר>
```
דווח: סטטוס · **ספירת נמענים** · אישור שהתבנית נרנדרה · אישור שאפס נשלחו.

**תנאי עצירה — כולם STOP, לא "לתקן ולנסות שוב":**
- ריצה נכשלה → הדבק שגיאה, אל תנסה שוב
- ספירה חורגת מהצפוי → ההגדרה שגויה, **אל תשנה את השאילתה מיוזמתך**
- ספירה 0 → dedup או הגדרה חוסמים. זה **ממצא**, לא מכשול לעקוף

### 4. ⛔ עצירה קשיחה
המתן למשפט המדויק: **`אשר שליחה חיה`**
"כן" · "אוקיי" · "תשלח" · "קדימה" — **אינם אישור.** שאל שוב.

### 5. שליחה + אימות
אותה פקודה עם `dry_run=false`. **אל תשנה שום פרמטר אחר.**
```sql
select count(*) from email_campaign_log
where campaign='<שם>' and status='sent';
```
המספר חייב להיות זהה לדיווח. פער = דיווח שלא תואם מציאות → דווח מיד.
ודא שדוח 📧 הגיע לדיסקורד. **לעולם לא הרצה שלישית.**

## פרטיות — חוצה כל השלבים

- ⛔ **אפס כתובות מייל בפלט, בלוגים, ובצ'אט.** ספירות ותאריכים בלבד.
- מזהי משתמש — 8 תווים ראשונים בלבד.
- לעולם לא לשלוח תוכן יומן (`notes`, `lessonLearned`) לשום מקום.

## מגבלות

| מה | ערך |
|---|---|
| Gmail SMTP | ~300 נמענים/יום. מעבר — Resend + דומיין |
| השהיה | 3 שניות בין מיילים (workflow) / 300ms (`send-invites`) |
| `limit` ברירת מחדל | **10** — לשנות במפורש |
| `dry_run` ברירת מחדל | `true` — לא לשנות בקוד |

## אסור

- לשנות `dry_run`/`limit`/קהל קיים בקוד כדי "להקל"
- ליצור טוקן, לאמת `gh` מחדש, או לגעת ב-secrets. אין הרשאה → STOP, ניב מריץ מה-UI
- לגעת ב-`api/send-invites.js`
- לשלוח לאדמין את השאלה למה הוא לא משתמש באפליקציה שלו
